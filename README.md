# PhishGuard 🔐

PhishGuard is a machine learning-based phishing detection system
designed to analyze URLs and emails and identify potential phishing attacks.

## Features

- 🔗 URL phishing detection
- 📧 Email phishing detection
- 🤖 Machine learning-based classification
- 📊 Risk/confidence analysis
- 🌐 Web-based interface
- ⚡ Fast API backend

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- XGBoost
- FastAPI
- HTML
- CSS
- JavaScript
- Git & GitHub
